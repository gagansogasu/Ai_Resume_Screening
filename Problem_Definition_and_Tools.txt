AI Resume Screening & Ranking System - Project Overview

================================================================================
1. Problem Definition
================================================================================
The process of manually screening hundreds of resumes against a job description is highly time-consuming, subjective, and prone to human error. Traditional Applicant Tracking Systems (ATS) often rely on rigid, exact keyword matching. This legacy approach fails to capture the true semantic meaning and context of a candidate's experience. For instance, a candidate might possess the required skills but use slightly different terminology, causing them to be wrongly filtered out by a traditional ATS.

The objective of this project is to build an intelligent, AI-powered Resume Screening & Ranking System. It aims to automate the resume screening process by leveraging Deep Learning (BERT) and Natural Language Processing (NLP) to understand the context and semantics of both the candidate's profile and the job description. The system evaluates and ranks candidates based on an advanced hybrid scoring model (combining Deep Semantic Similarity, Contextual Keyword matching, and Section-specific analysis), providing recruiters with an interactive, transparent, and data-driven visualization of candidate alignment.

3. In-Detail: How and Why Each Tool is Used
================================================================================

1. Streamlit
   - How it is used: Streamlit acts as the entire frontend and web application framework (`app.py`). It provides the user interface for uploading multiple PDF resumes, pasting the job description, and navigating between the "Upload" and "Results" tabs.
   - Why it is used: It allows for rapid development of data-driven Python web applications without needing a separate frontend framework (like React). It natively integrates with Python data structures (Pandas, Plotly) and handles state management easily, making it perfect for building interactive AI dashboards.

2. Sentence-Transformers (all-MiniLM-L6-v2)
   - How it is used: Deployed in `resume_processing.py` to convert text (from both resumes and the job description) into high-dimensional vector representations (embeddings).
   - Why it is used: Unlike basic keyword matching, BERT models understand the context and semantic meaning of text. `all-MiniLM-L6-v2` was specifically chosen because it is highly efficient and fast while maintaining excellent accuracy for sentence-level semantic similarity tasks. It drives the "Global Semantic Fit" score, which accounts for 60% of the candidate's final rank.

3. Transformers / DistilBART (sshleifer/distilbart-cnn-12-6)
   - How it is used: Used to generate an "AI Recruiter Summary" for each candidate. The model takes the raw text of the resume and generates a concise, 3-bullet abstractive summary highlighting the candidate's core profile.
   - Why it is used: DistilBART is a distilled (compressed) version of the original BART model. It was chosen because it is 70% lighter and significantly faster, while still maintaining high-quality abstractive summarization capabilities. This helps recruiters get a quick glance at the candidate's profile without reading the entire document.

4. pdfplumber
   - How it is used: Utilized in the `extract_text_from_pdf` function to read uploaded candidate resumes (.pdf format) and extract the raw string text from them, page by page.
   - Why it is used: PDFs are the absolute industry standard for resumes. `pdfplumber` was chosen because it is highly robust and particularly good at extracting text accurately while respecting the layout of complex documents, which is essential for parsing structured formatting often found in resumes.

5. Scikit-learn (Cosine Similarity & CountVectorizer)
   - How it is used: 
     * `cosine_similarity` calculates the mathematical distance between the BERT embeddings of the job description and the resumes.
     * `CountVectorizer` is used in the custom KeyBERT-style keyword extraction process to generate n-gram candidates from the text.
   - Why it is used: Scikit-learn provides highly optimized, industry-standard mathematical primitives. Cosine similarity is the standard metric for comparing dense vectors (embeddings) generated by deep learning models.

6. NLTK (Natural Language Toolkit)
   - How it is used: Used in the `preprocess_text` function to download and remove "stop words" (common English words like 'the', 'is', 'in') from the extracted text.
   - Why it is used: Removing stop words drastically reduces noise in the text data. This allows the Machine Learning models to focus purely on the technical and relevant content (skills, experience nouns) when extracting keywords and generating embeddings.

7. Plotly (Plotly Express & Graph Objects)
   - How it is used: Rendered inside the Streamlit app to create the "Candidate Rankings" horizontal bar chart and the detailed "Semantic Breakdown" radar chart.
   - Why it is used: Plotly provides highly interactive charts (hover data, distinct color scales) out of the box. The visual feedback—especially the radar charts that break down scores into Experience, Education, and Skills—is crucial for explaining the AI's ranking decision transparently to the recruiter.

8. Pandas
   - How it is used: Used to structure the final output of the Python ranking algorithm into structured DataFrames.
   - Why it is used: DataFrames are the standard way to handle tabular data in Python. They are easily rendered by Streamlit into clean UI data tables and are natively supported by Plotly for creating visualizations without complex data transformations.
